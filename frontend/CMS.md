# Sanity CMS Documentation for School Owners

Complete guide to managing your school website content from Sanity CMS dashboard.

## What is Sanity CMS?

Sanity CMS is a headless content management system that lets you:
- ✅ Update website content without coding
- ✅ Upload images and documents
- ✅ Publish changes instantly
- ✅ Manage all school information in one place

**No technical knowledge required!**

## Getting Started

### Access Sanity Dashboard

1. Visit: https://sanity.io/
2. Click "Sign In" (top right)
3. Sign in with your Sanity account
4. You'll see your project dashboard

### Dashboard Overview

- **Left Sidebar**: Different content types (pages/sections)
- **Main Area**: Edit content here
- **Top Bar**: Publish, Preview, Settings

## Content Types (What You Can Edit)

### 1️⃣ Homepage

**Location**: Sanity Dashboard → "Home Page"

**Edit:**
- **Hero Title** - Main title on home page
- **Hero Tagline** - Subtitle under title
- **Hero Image** - Background banner image
- **Welcome Message** - Text below hero
- **CTA Buttons** - "Learn More", "Admissions" buttons

**Steps to Update:**
1. Click "Home Page" in sidebar
2. Edit text fields
3. Click image field to upload new image
4. Click "Publish" at top right
5. Changes live in seconds!

---

### 2️⃣ About Page

**Location**: Sanity Dashboard → "About Page"

**Edit:**
- **School Name** - Your school's official name
- **School Logo** - Upload logo image
- **Mission Statement** - Your school's mission
- **Vision Statement** - Your school's vision
- **School History** - Long description (rich text)
- **Principal's Message** - Message from principal
- **Principal's Name** - Principal's name
- **Principal's Image** - Principal's photo
- **Highlights** - Key features (Smart Classrooms, Labs, etc.)

**How to Add Highlights:**
1. Scroll to "School Highlights" section
2. Click "+ Add Highlight"
3. Fill in:
   - Title (e.g., "Smart Classrooms")
   - Description
   - Icon name (e.g., "FaDesktop")
4. Click "Publish"

---

### 3️⃣ Faculty

**Location**: Sanity Dashboard → "Faculty" (left sidebar)

**Each Faculty Profile Contains:**
- Photo
- Name
- Subject/Department
- Qualification
- Years of Experience
- Email
- Phone
- Short Description

**How to Add a Teacher:**
1. Click "Faculty" in left sidebar
2. Click "+ Create" button
3. Fill in all information:
   - Upload photo
   - Enter name
   - Select subject
   - Add qualification
   - Years of experience
   - Email and phone
4. Click "Publish"

**How to Edit Teacher:**
1. Click teacher name in list
2. Make changes
3. Click "Publish"

**How to Delete Teacher:**
1. Click teacher name
2. Click "Delete" button (top right)
3. Confirm deletion

---

### 4️⃣ Notices/Announcements

**Location**: Sanity Dashboard → "Notice"

**Each Notice Contains:**
- Title
- Description (rich text - can format)
- Date & Time
- Category (General, Admission, Exam, Event, Holiday, Academic)
- Important Flag (highlights as urgent)
- PDF Attachment (optional)

**How to Create Notice:**
1. Click "Notice" in sidebar
2. Click "+ Create"
3. Fill in:
   - **Title**: What's the announcement about?
   - **Description**: Full details (can use bold, italic, etc.)
   - **Date**: When posted/effective date
   - **Category**: Select from dropdown
   - **Mark as Important**: Toggle for urgent notices
   - **PDF**: Optional attachment
4. Click "Publish"

**Tip:** Important notices appear at top of notices page automatically!

---

### 5️⃣ Gallery

**Location**: Sanity Dashboard → "Gallery"

**How to Create Gallery Album:**
1. Click "Gallery" in sidebar
2. Click "+ Create"
3. Fill in:
   - **Title**: Event name (e.g., "Sports Day 2024")
   - **Category**: Select (Event Images, Campus Photos, Annual Function, Activity Photos)
   - **Description**: Optional details
   - **Date**: When event happened
   - **Images**: Upload multiple images
4. Click "Publish"

**How to Upload Multiple Images:**
1. In "Gallery Images" field, click upload area
2. Select multiple images from your computer
3. Images appear in grid
4. Drag to reorder if needed
5. Click "Publish"

**Supported Image Formats:**
- JPG, PNG, GIF, WebP
- Max 10MB per image
- Recommended: 2-5MB for web

---

### 6️⃣ Videos

**Location**: Sanity Dashboard → "Video"

**How to Add YouTube Video:**
1. Click "Video" in sidebar
2. Click "+ Create"
3. Fill in:
   - **Title**: Video name
   - **Description**: Optional details
   - **Category**: (School Introduction, Annual Day, Student Activities, Events, Other)
   - **Video URL**: Paste YouTube/Vimeo link
     - YouTube example: `https://www.youtube.com/watch?v=dQw4w9WgXcQ`
     - Vimeo example: `https://vimeo.com/76979871`
   - **Thumbnail**: Optional custom image (else auto-generated)
4. Click "Publish"

**Where to Find Video URLs:**
- **YouTube**: Click "Share" → Copy link
- **Vimeo**: Click "Share" → Copy link

---

### 7️⃣ Testimonials

**Location**: Sanity Dashboard → "Testimonial"

**How to Add Testimonial:**
1. Click "Testimonial" in sidebar
2. Click "+ Create"
3. Fill in:
   - **Name**: Person's name
   - **Role**: Select (Parent or Student)
   - **Feedback**: What they say (quote)
   - **Profile Image**: Optional photo
   - **Rating**: 1-5 stars
4. Click "Publish"

**Example:**
- Name: "Raj Kumar"
- Role: Parent
- Feedback: "Excellent school with caring teachers and great facilities!"
- Rating: 5 stars

---

### 8️⃣ Achievements

**Location**: Sanity Dashboard → "Achievement"

**How to Add Achievement:**
1. Click "Achievement" in sidebar
2. Click "+ Create"
3. Fill in:
   - **Title**: Award name (e.g., "Best School Award 2024")
   - **Description**: Details about achievement
   - **Type**: (School Award, Certification, Major Achievement, Event Accomplishment)
   - **Date**: When achieved
   - **Image**: Optional photo
   - **Details**: Additional information
4. Click "Publish"

---

### 9️⃣ Contact Information

**Location**: Sanity Dashboard → "Contact"

**How to Update:**
1. Click "Contact" in sidebar (should have one entry)
2. Edit:
   - **Phone**: Main phone number
   - **Email**: Contact email
   - **WhatsApp Number**: Phone for WhatsApp (with country code, e.g., +911234567890)
   - **Address**: School address
   - **City, State, Pincode**: Location details
   - **Google Maps Embed**: Embed code from Google Maps
   - **Office Hours**: Add days and times
3. Click "Publish"

**Get Google Maps Embed:**
1. Visit [Google Maps](https://maps.google.com)
2. Search for your school address
3. Click "Share" button
4. Click "Embed a map" tab
5. Copy the iframe src URL
6. Paste in Sanity

## Publishing Content

### How to Publish

Every content type follows same process:

1. **Make Changes** - Edit any field
2. **Review** - Check all information is correct
3. **Click "Publish"** - Top right button
4. **Confirm** - Click "Publish" in popup
5. **Website Updates** - Changes live in seconds!

### How to Save as Draft (Not Publish)

1. Make changes
2. Click "Save" instead of "Publish"
3. Content saved but not visible on website
4. Publish later when ready

### How to Unpublish (Remove from Website)

1. Open published content
2. Click "..." (more options)
3. Select "Unpublish"
4. Content removed from website (still in CMS)

---

## Uploading Media (Images & Documents)

### Upload Image

1. Click image field
2. Click "Upload" button
3. Select image from computer
4. Wait for upload
5. Appears automatically

### Upload PDF (For Notices)

1. In Notice, scroll to "PDF Attachment"
2. Click upload area
3. Select PDF file
4. Upload completes
5. Link appears in notice

### Best Practices

**Images:**
- Use modern formats (JPG, PNG)
- Resize to 2-5MB before uploading
- Recommended sizes:
  - Hero image: 1920x1080px
  - Faculty photo: 400x500px
  - Gallery: 1200x800px

**PDFs:**
- Keep under 5MB
- Clear, readable PDFs
- Include date/version info

## Tips & Tricks

### Reordering Items

Some content types have "Display Order":
1. Open item
2. Change order number (1, 2, 3, etc.)
3. Publish
4. Items sort by order

### Formatting Text (Rich Text)

In text fields with formatting options:
- **Bold**: `Ctrl+B` or click **B** button
- *Italic*: `Ctrl+I` or click *I* button
- Headings: Select text, click "Heading 1/2/3"
- Lists: Click list button
- Links: Click link icon, paste URL

### Duplicate Content

1. Open item
2. Click "..." menu
3. Select "Duplicate"
4. Creates copy
5. Edit and publish as new

### Search Content

1. Use search bar at top
2. Type keyword
3. Results appear
4. Click to open

## Troubleshooting

| Issue | Solution |
|-------|----------|
| Changes not showing | Click "Publish" button (not just "Save") |
| Image won't upload | Check file size (<10MB), try different format |
| Document not uploading | Make sure it's PDF, under 5MB |
| Can't find content | Use search bar, check sidebar menu |
| Website showing old data | Clear browser cache (Ctrl+Shift+Delete) |
